# Contributing

## Guidelines

- Keep changes focused and avoid altering the detection logic unless the task explicitly requires it.
- Preserve existing behavior in `main.py`, `streamlit_app.py`, and `gemini_engine.py`.
- Update documentation when user-facing usage changes.
- Run a syntax check or app launch before opening a pull request.

## Suggested workflow

1. Create a feature branch.
2. Make the smallest safe change.
3. Validate the affected entry point.
4. Submit a pull request with a concise summary of behavior impact.
